# Lightsabers — Real-Time Computer-Vision Jedi Lightsaber

A real-time webcam computer-vision application that turns detected hands into glowing Jedi-style lightsabers with fading luminous trails.

## Quick Start

### 1. Setup Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Run Application

```bash
python3 -m src.main
# or
python3 src/main.py
```

## Tech Stack

- Python 3
- OpenCV (`cv2`)
- MediaPipe Tasks Python Hand Landmarker
- NumPy
